## Publicación pendiente, sin bloquear la entrega del código

La consulta de Netlify no encontró proyecto JC existente. Sus herramientas conectadas no ofrecen aquí una operación de carga de archivos/despliegue y la CLI no tiene autenticación disponible. No se ha creado un proyecto vacío ni se ha iniciado sesión por navegador. Sites sí ofrece publicación privada, pero su flujo crea un repositorio fuente adicional: no se ejecutó porque Work 05 prohíbe crear otro repositorio sin consultar.

Decisión concreta necesaria para una URL alojada: elegir y autorizar un destino de vista previa compatible con estas restricciones. Puede ser un nuevo destino dedicado en Netlify con despliegue de la carpeta `web/`, sin tocar otros sitios; o Sites si se autoriza expresamente su repositorio fuente interno adicional. No se conectan servicios, cambian permisos de producción o configura GitHub Pages por inferencia. El PR y los archivos exportables quedan listos antes de esa decisión.
