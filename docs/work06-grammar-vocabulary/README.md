# Work 06 — Ampliación de Grammar y Vocabulary

22 de octubre de 2026 · Implementación para revisión docente · Rama `work06-grammar-vocabulary`.

La versión anterior era una introducción funcional: siete talleres de cuatro huecos y 26 grupos léxicos con 149 entradas. Esta entrega amplía las dos áreas, mantiene las seis secciones y conserva los ejercicios anteriores. No se declara que una temática esté completa por su número de preguntas.

- [Estados de cobertura y justificación](auditoria-estados.md).
- [Comprobación delimitada de soler en el corpus](soler-corpus.md).
- [Matriz gramatical anterior/nueva](matriz-grammar.md).
- [Matriz de los quince bloques](matriz-vocabulary.md).
- [Inventario y funcionamiento](inventario.md).
- [Fuentes y comparación con Tapitas](fuentes-y-criterios.md).
- [Pruebas y límites](pruebas.md).
- [Lagunas y prioridades](pendientes.md).

Grammar ofrece veinte apartados, con 357 ítems nuevos distribuidos entre interpretación, conjugación/compleción y corrección/transformación; cada apartado añade una tarea de producción con modelo posterior y autocotejo. Se añaden tres textos mixtos con 24 huecos: **381 ítems nuevos** en total. Los 28 huecos iniciales siguen accesibles como introducción. Hay variedad de personas y contextos, sin exigir el dominio productivo de todos los paradigmas receptivos.

Vocabulary reúne 499 entradas de aprendizaje: 376 entradas redactadas o contextualizadas para este banco y 122 etiquetas heredadas que no coinciden exactamente con las nuevas, más una referencia docente compartida entre dos bloques. No son 499 palabras distintas: una entrada puede agrupar variantes, contener expresiones o solaparse semánticamente con otra. El banco conserva referencias a sus grupos OL de origen. Los 26 grupos anteriores permanecen accesibles con sus actividades.

Los quince bloques tienen repertorio esencial/ampliado, tandas elegibles de hasta ocho entradas, reconocimiento en contexto, cinco u ocho compleciones, una fuente nueva con cuatro preguntas y una tarea de uso. Hay 90 compleciones, 64 preguntas con evidencia y quince propuestas de producción léxica. La práctica no recibe etiquetas de simulación oficial ni se atribuye comprensión auditiva a una lectura.

El ámbito docente de Work 06 autoriza esta ampliación. La selección esencial/ampliada y la dificultad son decisiones pedagógicas para revisión, no listas oficiales SEC/NCCA. No se han alterado los criterios aprobados ni añadido disposiciones oficiales nuevas.

Ejecución: servir la raíz del repositorio o `web/`. La raíz conserva el punto de entrada de GitHub Pages. Pruebas: `node tests/content.cjs` y `node tests/work06.cjs`. Exportación autónoma: `node scripts/export-preview.cjs`.
