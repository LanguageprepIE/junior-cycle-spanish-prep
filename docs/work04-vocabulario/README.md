## Propuesta para decidir

15 bloques comunicativos, incluidos dos ejes transversales; 18 grupos OL de entrada (109 ítems) y 8 de consolidación (40), con 14 grupos de reserva (74). Los grupos no se convierten automáticamente en unidades JC. Las ampliaciones de ropa, comida, cifras/horarios, ciudad/transporte y enlaces funcionales se trabajan junto al repertorio existente.

Se distingue **Recognise / Understand / Use**, con producción selectiva y comprensión más amplia, dentro de **Aprender → guiada → independiente → examen cuando corresponda**. De los 26 grupos iniciales, 25 conservan contenido y práctica guiada; uno requiere ajustes menores de equivalencia. La transferencia independiente necesita otros contextos, no repetir los mismos huecos con pistas.

Los ejemplos cubren instituto/preferencias, billetes/horarios y experiencias/planes. Son originales en papel para revisión. La Study Guide se diseña para orientar objetivos, práctica, errores y progreso; Study Plan y Tracker no tienen calendario fijado.

Base: Work 01–03 en main; no se repiten auditorías ni se alteran criterios v1.0. Las nuevas propuestas requieren aprobación docente. Este PR documental no autoriza desarrollo o edición de OL y **no se fusiona sin aprobación expresa**.
