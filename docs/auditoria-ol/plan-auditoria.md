# Plan de auditoría de recursos de LC Ordinary Level

**Repositorio de referencia (solo lectura):** https://github.com/LanguageprepIE/informal-letter-ol

## Objetivo
Identificar qué materiales existentes pueden servir a Junior Cycle sin asumir que una actividad completa sea transferible.

## Unidades de evaluación
- **Listening:** audio original y conjunto de preguntas por separado.
- **Reading:** texto original y conjunto de preguntas por separado.
- **Vocabulary:** banco completo, organización y lagunas temáticas.
- **Writing:** tareas de JC nuevas; examinar solo mecanismos, apoyos o estructuras aprovechables.
- **Sentence building / Grammar:** separar funcionalidad reutilizable de contenido que requiere adaptación.

## Dictamen por componente
- A: reutilizable tal cual.
- B: conservar fuente y rehacer preguntas.
- C: adaptar contenido.
- D: no adecuado para JC.

Registrar para cada recurso: identificador, tema, archivo/ruta, nivel de dificultad, naturalidad, alineación con formatos SEC, apoyos necesarios, dictamen razonado y prioridad.

## Secuencia
1. Inventariar recursos reales del repositorio OL.
2. Contrastar con la matriz oficial de JC.
3. Evaluar cada texto/audio independientemente de las preguntas.
4. Identificar lagunas y oportunidades de reutilización.
5. Presentar conclusiones al profesor antes de autorizar desarrollo.

**Prohibido:** modificar OL, crear una web JC o fusionar cambios de código sin autorización expresa.
